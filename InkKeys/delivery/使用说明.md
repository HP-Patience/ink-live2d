## 可用动作

- 空闲自动眨眼、呼吸和头发轻微物理。
- 鼠标移动驱动头部、视线和鼠标手；左右键驱动鼠标手按压。
- 键盘按下驱动键盘手，松开回到原位；包含字母、数字、常用符号、修饰键、方向键、F1–F24 和数字小键盘的命名适配。
- 模型含张嘴、转头、歪头参数，方便后续编辑；本包不包含摄像头跟踪、语音口型自动输入或手柄专用布局。

## 注意

`resources/left-keys` 现在是真正的逐键手部落点与高亮图，不再是相同的透明触发文件。键盘手由 BongoCat 原生覆盖层按实际键位切换，待机手由 Live2D 隐藏/恢复；人物、眨眼、呼吸和鼠标手仍由 MOC3 网格驱动。不要删除该目录。

当前修正版：鼠标横向范围扩大 6 倍、纵向扩大 4 倍；标准 QWERTY、方向键、小键盘以及左右 Shift/Ctrl/Alt 分别映射。多键同时按下时显示最后一个，松开该键回待机，这是原生软件的单手规则。主 Enter 和小键盘 Enter、左右 Windows 键分别被软件合并，无法由皮肤区分。

这版保留用户确认的造型，自动分层后补齐了头发/脸/眼镜/袖子/手/鼠标遮挡。人物和桌面分别绑定，桌面不会跟随头部变形。极端写实大角度不是该 Q 版桌宠的设计范围。

## 复现（使用保存的最终分层，不必重新推理）

解压 `InkKeys-Source.zip`，进入其中的制作目录。需要 Python 3.12、Java 21；模型重建可在 CPU 上运行。

```powershell
python -m venv workspace/venv
workspace/venv/Scripts/python.exe -m pip install pillow numpy
workspace/venv/Scripts/python.exe tools/setup_tools.py
workspace/venv/Scripts/python.exe tools/rebuild.py
workspace/venv/Scripts/python.exe tools/test_native.py
```

`setup_tools.py` 下载 PSD2Live 0.7.1 并核验 SHA-256。若只想在 Cubism Editor 中修改，直接打开 `source/InkKeys.cmo3`；分层绘画在 `source/InkKeys.psd`。

若要复现图层修复，还需安装 `psd-tools==1.14.2 opencv-python`，保留打包的 `workspace/inference-output/inference-input/`，再依次运行 `prepare_source.py`、`extract_input_parts.py`、`make_input_layout.py`、`repair_layers.py`。这些坐标修复仅适用于本次确认的原画。

CMO3 的可编辑图层由导出纹理重建，未保留 Photoshop 到 Cubism 的原始关联编辑链；因此另交付原始 PSD 与独立 PNG。
