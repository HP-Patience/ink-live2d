## 已知限制

- **未在 Cubism Editor 桌面 GUI 打开复验，也未进行 VTube Studio 摄像头实测。** CMO3 经导出器回读检查，不是全软件兼容认证。
- 数值有限、参数可动不代表全部极端姿态达到商业精修标准。眼镜透视、侧脸、发束和大幅头颈衔接仍可精修。
- 原画为闭嘴正面肖像，口腔为简化补绘，没有完整 A/I/U/E/O 独立音素，也没有完整背面或下半身。
- 头顶、后发、后衣领含纹理延展或局部补全，并非原画师手绘完整多角度素材；物理以大片前后发为主。
- 导出日志含鼻部/闭口小组件的网格边界警告，保留原日志，不称为零警告。
- 图层复现以保存输入为基准；不保证 Java 导出文件或 GPU 重推理的字节级一致。
- 截图与动画展示选定姿态，不覆盖全部参数组合。
