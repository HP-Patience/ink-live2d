# InkPortrait — Live2D v6

基于你提供的黑白人物肖像制作。交付的是实际 Live2D 模型，不是把一张静态图片上下晃动的网页效果；GIF / MP4 只是从模型运行画面录出的预览。

## v6 脖颈倾角与后衣领

- 按标注将脖子右侧直线改为向下向内收，形成上宽下窄的轮廓；不改变原脖子纹理。
- 补全独立的后衣领图层，按由后向前的“后衣领 → 脖颈 → 前衣领”顺序绘制，跟随衣服而非头部，遮住收窄后露出的空隙。
- 其余原有 18 个非脖子图层保持不变。新增后衣领是基于原衣服暗色纹理的局部补全。
- 网页鼠标歪头范围仍为 −12°～12°，其他映射不变；此播放器限制不会自动带入其他播放器。
- 已重新检查左右转头和正脸；参数边界、睫毛、组合姿势与衣领遮挡顺序/身体跟随检查通过。

## v3 修复（历史）

- 按用户要求恢复 v2 的脖颈贴图与轮廓，撤销收窄及纹理修改；大幅歪头时原先的脖颈露边也随之保留。
- 画布顶部留白增加 160 像素，但实际头顶仅向上延展约 35 像素（撤销上一稿约 100 像素的高凸顶冠），使用较低的弧线延续原发丝，旋转时不再暴露原图的直线裁切口；未缩小角度参数范围。
- 36 项参数边界检查、8 项睫毛位移回归检查通过；另检查 12 个左右转头 ±45、俯仰 ±30/0、歪头 ±30 组合姿势的有限坐标，并目视检查其头顶与脖颈。
- 保留 v2 的下睫毛绑定和后发耳朵残影修复。头顶补区纹理经过拉伸，精细发束仍可继续手绘优化。

## v2 修复（保留）

- 两侧下睫毛分别绑定至对应眼睛的形状变形器；不再仅跟随脸部。
- 清除后发贴图中复制的耳朵与脸颈白边，补为深色后发；真正耳朵仍独立运动。
- 未缩小原参数范围。重新通过 36 项参数边界检查、8 项上下睫毛位移回归检查和 4 个组合极限角度的有限坐标检查，并目视检查左右转头。
- 同一睫毛回归脚本在旧版可重现失败、在 v2 通过。网格平均纵向位移差最大值由约 0.01350 降至 0.00127（模型坐标）。
- 本次后发补区采用深色纹理延展，细密发丝可继续手绘精修；不是重绘原画。
- 更新时备份你自己的 VTube Studio 配置，只替换模型运行文件；本包未做摄像头实测。

## 文件

- `models/InkPortrait/`：完整运行模型。导入时保留整个文件夹，不要只复制 moc3。
- `source/InkPortrait.cmo3`：PSD2Live 导出的可编辑 Cubism 工程。
- `source/InkPortrait.psd`：修复后源图，20 个 RGBA 部件图层，1280 × 1440。
- `validation/`：官方运行时参数检查结果、导出器检查日志。

模型包含 23 个网格、4,585 个顶点、18 个参数、1 张 4096 × 4096 贴图，以及前后发/眼球物理配置。

## 导入 VTube Studio

1. 解压本包。
2. 在 VTube Studio 中打开模型数据文件夹，找到 `Live2DModels`。
3. 将本包里的整个 `models/InkPortrait` 文件夹放进去。
4. 重新打开 / 刷新模型列表，选择 InkPortrait，运行 Auto-Setup。
5. 首次使用根据摄像头调整输入映射。下面是这个模型的建议输出范围，不是要求改变原始参数定义。

| 功能 | Live2D 参数 | 建议预览 / 跟踪输出范围 |
|---|---|---|
| 左右转头 | ParamAngleX | -25 ～ 25 |
| 抬头低头 | ParamAngleY | -18 ～ 18 |
| 歪头 | ParamAngleZ | -12 ～ 12 |
| 左右眼开合 | ParamEyeLOpen / ParamEyeROpen | 0 ～ 1 |
| 视线 | ParamEyeBallX / ParamEyeBallY | -0.8 ～ 0.8 |
| 张嘴 | ParamMouthOpenY | 0 ～ 0.7；1 为最大口型 |
| 嘴角表情 | ParamMouthForm | -0.5 ～ 0.5 |
| 左右眉毛 | ParamBrowLY / ParamBrowRY | -1 ～ 1 |
| 身体角度 | ParamBodyAngleX/Y/Z | -5 ～ 5 |
| 呼吸 | ParamBreath | 0 ～ 1 |

ParamHairFront / ParamHairBack / ParamEyeBallForm 由物理配置驱动，通常不需要映射到摄像头。

本次验证环境为官方 Cubism SDK for Web 5-r.5；没有在你的 VTube Studio 内做摄像头实测，也没有伪造 .vtube.json 设备配置。导入与 Auto-Setup 流程依据 VTube Studio 官方说明（2026-09-17 查阅）：
https://github.com/DenchiSoft/VTubeStudio/wiki/Loading-your-own-Models

## 画面范围与限制

这是一张正面、闭嘴、黑白插画制作出的第一版半身模型，不等同于原画师为大角度专门补绘的商业精绑模型。

- 自动分层对脸部和衣服错分严重，已重新制作脸底、衣服和隐藏脖颈，清理后发/耳朵，拆开上下眼线，并保留原图的黑白发丝、眼镜和冷淡表情。
- 张嘴内部是补绘的简化黑白口腔；原图没有张嘴参考。没有完整 A/I/U/E/O 独立音素口型。
- 采用小到中等幅度转头；参数极值通过数值检查不代表每个极端姿势都达到了商业精修标准，特别是眼镜透视、侧脸和头颈衔接。
- 发丝物理以整片前发、后发为主，不是每根发束独立绑定。
- 原图头顶已被裁切；v3 扩展画布并以现有发丝纹理弯曲延展出圆弧顶冠，消除直线裁切口。这是近似补全，并非原画师手绘完整头顶；未补背面或下半身。
- CMO3 的纹理编辑层由导出贴图页重建，未保留 Photoshop 到 Cubism 的原始链接编辑链；需要改画时另外提供的 PSD 更合适。
- 导出日志保留了鼻部/闭口小组件的网格边界偏差警告。已经目视检查，但没有将这些警告包装成零瑕疵。
